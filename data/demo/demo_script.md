# IBMS Demo Script (Member D - Data, Design & QA)

## 🔹 Introduction (Problem Statement)

Right now, Agaram coordinators manage student data across multiple spreadsheets — one for Vidhai, one for Mentorship, one for Hostels, and one for Fellowship.

The problem is, the same student appears differently in each sheet. There is no unified view, and tracking a student’s journey becomes extremely difficult and time-consuming.

---

## 🔹 CSV Upload & AI Mapping (Main Part)

Here we are uploading different CSV files from different programs.

Each file has completely different column names and structures. For example, one file uses "student_name", another uses "beneficiary", and another uses "name".

Despite this inconsistency, our system uses AI to automatically understand and map these columns to a unified schema.

Even when student names vary slightly, like "Selvaraj P" and "Priya Selvaraj", our system intelligently detects possible matches using fuzzy logic.

This allows us to merge multiple records into a single unified student profile.

---

## 🔹 Key Highlight

So instead of manually cleaning and combining data, the system does it automatically in seconds.

---

## 🔹 Transition

Once the data is unified, coordinators can now work entirely within the system — no more spreadsheets.

---

## 🔹 Closing Line

Today, we transformed scattered, inconsistent data into a single, intelligent system that not only tracks students, but also tells their story and highlights those who need attention.
